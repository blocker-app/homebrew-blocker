# Homebrew Blocker

Homebrew tap for [Blocker](https://getblocker.app), a minimal macOS website blocker with recurring schedules.

Website: https://getblocker.app

## Install

```bash
brew install --cask blocker-app/blocker/blocker
```

## Update

```bash
brew upgrade --cask blocker
```

## Uninstall

```bash
brew uninstall --cask --zap blocker
```

## Requirements

macOS 12 (Monterey) or later. Apple Silicon and Intel are both supported.

## Source

The application source lives in a private repository. Signed and notarized release binaries are published at [`blocker-app/blocker-releases`](https://github.com/blocker-app/blocker-releases).
